# Textarea

Wieloliniowe pole tekstowe na stronach admina (shadcn): rośnie wraz z treścią.

<Canvas of={TextareaStories.Default} />

<Canvas of={TextareaStories.Invalid} />

## Kiedy użyć

- Dłuższy tekst: notatka agenta, powód odrzucenia, opis problemu.
- Gdy odpowiedź może mieć kilka zdań.

Alternatywy: krótka wartość w jednej linii to `Input`; wybór z listy to `Select`.

## Kiedy nie użyć

- Dla krótkich wartości (nazwa, numer, e-mail) — użyj `Input`.
- Do edycji sformatowanego tekstu — komponent obsługuje tylko czysty tekst.
- Na stronach publicznych — tam użyj odpowiednika z pakietu `public`.

## Jak złożyć

```tsx
import { ErrorMessage, Label, Textarea } from "@easyrms/ui/admin";

<div className="space-y-1">
  <Label htmlFor="note">Notatka dla klienta</Label>
  <Textarea id="note" name="note" aria-invalid={!!error} aria-describedby="note-error" />
  {error ? <p id="note-error"><ErrorMessage message={error} /></p> : null}
</div>
```

- Zawsze `Label` z `htmlFor` zgodnym z `id`.
- Wysokość: minimum `min-h-16`, potem rośnie z treścią (`field-sizing-content`); aby ograniczyć, dodaj `max-h-*` w `className`.
- Błąd: `aria-invalid` i `ErrorMessage` pod polem.

## Tokeny

`border-[1.5px] border-input`, `bg-card`, `placeholder:text-muted-foreground`, fokus `border-primary` + `ring-[3px] ring-ring/35`, invalid `border-destructive` + `bg-destructive-subtle`, `rounded-md`, `text-base`, min. wysokość `min-h-24`. To samo ciało co `Input`.

## Stany

| Stan | Zachowanie | Jak wywołać |
|---|---|---|
| default | Ramka `border-input`, placeholder przygaszony. | domyślnie |
| filled | Wartość w kolorze tekstu; pole rośnie. | `value` lub `defaultValue` |
| focus-visible | Obrys 3 px `ring-ring/35` i `border-ring`. | klawiatura lub kliknięcie |
| disabled | `opacity-50`, `cursor-not-allowed`. | `disabled` |
| invalid | `border-destructive`, pierścień `ring-destructive/20`. | `aria-invalid` |

## Dostępność

- To natywny `textarea`; klawiatura i autouzupełnianie pochodzą z przeglądarki.
- Etykieta: `Label` z `htmlFor` lub `aria-label`; placeholder nie jest etykietą.
- `aria-invalid="true"` zmienia wygląd; komunikat dołącz przez `aria-describedby` i `ErrorMessage` (`role="alert"`).
- Gdy obowiązuje limit znaków, podaj go w tekście pomocniczym i ustaw `maxLength`.
