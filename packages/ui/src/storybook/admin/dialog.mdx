# Dialog

Okno modalne oparte na Radix `Dialog` (shadcn): przesłania stronę, przejmuje fokus i wymaga reakcji użytkownika.

<Canvas of={DialogStories.Closed} />

## Kiedy użyć

- Potwierdzenie akcji nieodwracalnej lub ryzykownej (odrzuć zwrot, usuń) — nazwij obiekt w pytaniu.
- Krótkie, skupione zadanie z 1–3 polami (np. powód odrzucenia).

Alternatywy: komunikat bez wymaganej decyzji to `Alert`; komunikat o błędzie pola to `ErrorMessage`; podpowiedź to `Tooltip`; długi formularz to osobna strona z `CrudForm`.

## Kiedy nie użyć

- Do długich formularzy lub treści z przewijaniem — użyj strony.
- Do komunikatów informacyjnych, które nie wymagają decyzji — użyj `Alert`.
- Do podpowiedzi — użyj `Tooltip`.
- Na stronach publicznych — nie ma publicznego odpowiednika; unikaj modalnych okien w procesie klienta.
- Dialogu w dialogu.

## Jak złożyć

```tsx
import {
  Button, Dialog, DialogClose, DialogContent, DialogDescription,
  DialogFooter, DialogHeader, DialogTitle, DialogTrigger,
} from "@easyrms/ui/admin";

<Dialog>
  <DialogTrigger asChild>
    <Button variant="destructive">Odrzuć zwrot</Button>
  </DialogTrigger>
  <DialogContent closeLabel="Zamknij">
    <DialogHeader>
      <DialogTitle>Odrzucić zwrot RMA-1042?</DialogTitle>
      <DialogDescription>Klient dostanie e-mail. Tej akcji nie można cofnąć.</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose asChild>
        <Button variant="outline">Anuluj</Button>
      </DialogClose>
      <Button variant="destructive" onClick={onReject}>Odrzuć zwrot</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

- Sterowanie: niekontrolowane (`defaultOpen`) lub kontrolowane (`open` + `onOpenChange`).
- Obowiązkowe: `DialogTitle`; `DialogDescription` zalecany (Radix ostrzega, gdy go brak).
- `DialogContent` ma przycisk zamknięcia (X); wyłączysz go przez `showCloseButton={false}`. Jego dostępna nazwa to `closeLabel` (domyślnie „Zamknij”).
- Przycisk anuluj opakuj w `DialogClose asChild`, by miał własną etykietę.

## Tokeny

`bg-card` (panel), wnętrze `p-5`, `border`, `shadow-lg`, `rounded-lg`, `bg-black/50` (tło przesłaniające), `text-muted-foreground` (opis), `ring-ring` i `ring-offset-background` (fokus przycisku zamknięcia), `bg-accent` (stan otwarty przycisku zamknięcia).

## Stany

| Stan | Zachowanie | Jak wywołać |
|---|---|---|
| closed | Nic nie jest renderowane. | domyślnie |
| open | Panel wyśrodkowany z animacją fade/zoom, tło przesłania stronę. | `DialogTrigger`, `open`, `defaultOpen` |
| focus-visible (zamknięcie) | Pierścień `ring-ring` 2 px z offsetem. | klawiatura |
| bez przycisku zamknięcia | Tylko akcje z `DialogFooter`. | `showCloseButton={false}` |

## Dostępność

- Radix: `role="dialog"`, `aria-modal`, `aria-labelledby` wskazuje `DialogTitle`, `aria-describedby` wskazuje `DialogDescription`.
- Fokus jest zatrzymany w oknie (focus trap), po otwarciu trafia do pierwszego elementu, po zamknięciu wraca do wyzwalacza.
- `Esc` zamyka okno; kliknięcie w tło również zamyka (zachowanie Radix).
- Treść pod oknem jest ukryta dla czytników ekranu.
- Deweloper musi podać: `DialogTitle`, najlepiej `DialogDescription`, a dla przycisku zamknięcia przetłumaczony `closeLabel`.
